# Dhaniya Rasheed — Portfolio

A responsive static portfolio website made with HTML, CSS and JavaScript.

## Preview
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Create a **public** repository named exactly `dhaniyauni241-mea.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` directly into the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. After publishing, the website address should be `https://dhaniyauni241-mea.github.io/`.

Before publishing, check that your phone number, email, project details and links are correct. The three GitHub project links are based on the public repositories shown in your screenshots.
